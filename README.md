# Product Design with Autodesk Inventor

WSQ courseware for **TGS-2021006715**, aligned to **Computer-Aided Design (PRE-DES-4036-1.1)**.

Course page: [WSQ Product Design with Autodesk Inventor](https://www.tertiarycourses.com.sg/wsq-product-design-with-autodesk-inventor.html)

## Current release

- Version: **v9.0**
- Release date: **20 August 2026**
- Duration: **2 days / 16 hours**
- Assessment: **Written Assessment (60 min) + Practical Performance (90 min)**

## Courseware

The `courseware/` folder contains the current trainer deck, learner-slide PDF, Learner Guide, Lesson Plan and slide map. The deck is conceptual and highly visual; detailed click-by-click procedures are in the Learner Guide and labs.

## Hands-on labs

The `labs/` folder contains eight progressive, self-contained labs. Every lab has:

- a detailed Markdown guide and same-folder PDF;
- native Autodesk Inventor sample files (`.ipt`, `.iam`, `.ipn`, `.idw` or `.ipj` as appropriate);
- scenario, evidence requirements, acceptance criteria and troubleshooting guidance.

## Distribution boundary

Assessment papers, answer keys, build tooling, source references, QA renders and credentials are intentionally excluded from this public repository. Learner-facing assessment papers are distributed through the LMS; answer keys remain trainer-only.
